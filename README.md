# Mold-Enterprise-Website
# 模具制造行业-企业官网源码
### 1、项目介绍
模具制造企业宣传站，把企业的制造功底、产品体系、工艺能力与交付案例，以结构化、可视化的方式搬到线上，让实力可被衡量，让信任有据可依！
### 2、功能介绍
① 系统管理后台：
- 系统管理：菜单管理, 角色管理, 账号管理, 网站配置
- 内容管理：关于我们, 核心优势, 首页配置
- 案例管理：案例分类, 工程案例, 页面配置
- 生产实力：核心数据, 设备展示, 工艺流程, 车间实景, 页面配置
- 产品管理：产品分类, 产品信息, 工艺能力, 页面配置
② 企业展示前台：
- 首页, 产品中心, 生产实力, 工程案例, 关于我们
